# PO & FE Acceptance Criteria Framework

이 문서는 Tenduck 프로젝트의 기획(PO)과 개발(FE) 간의 인수 검증 기준입니다.

---

## 1. 하네스 자동화 파이프라인

모든 태스크는 다음 3단계 파이프라인을 거쳐야만 완료(Done) 상태로 인정됩니다:

```text
[1. 기획 단계] PRD & WebSocket Contract 확정 
   -> [2. 개발 단계] anti-slop 가드레일 하에 기능 및 훅 개발
   -> [3. 검증 단계] Delivery Gate (npm run gate) 통과 & PO UI 승인
```

---

## 2. FE 성능 및 훅 활용 검증 항목 (PO/FE 공동 체크)

1. **`useTransition` & `useDeferredValue`**:
   - 실시간 토큰 스트리밍과 복잡한 Markdown 파싱/하이라이팅이 렌더링 스레드를 차단하지 않는가?
   - 사용자 입력 타이핑 시 랙이 0ms에 가깝게 유지되는가?
2. **`useCallback` & `useMemo`**:
   - WebSocket 이벤트 핸들러 및 메시지 필터링 함수가 불필요하게 재생성되지 않는가?
   - 수신된 토큰 누적 버퍼가 적절한 의존성 배열로 캐싱되는가?
3. **가상화 또는 버퍼 배치 (Batching)**:
   - WebSocket에서 수십 개의 패킷이 1초 안에 몰려올 때, React 19의 자동 배칭 및 `requestAnimationFrame`을 통해 프레임 드랍을 방어하는가?

## 3. 디자인 무결성 검증

- **색상**: 롯데 레드(`#DA291C`), 샴페인 골드(`#C5A880`), 딥 차콜(`#111111`)만 주 색상으로 사용되었는가?
- **AI Slop 배제**: 불필요한 그라데이션, 인위적 별빛 아이콘, 과장된 광고성 문구가 없는가?
- **웹소켓 연결 피드백**: 연결 중(노란색), 연결 완료(초록색), 끊김/재연결(빨간색/주황색) 상태가 명확한가?
